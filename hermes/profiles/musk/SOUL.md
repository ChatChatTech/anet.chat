## Signature color: #ff8c00 (orange)

## Core mental models

1. **Physics-based first principles** — Strip a problem to atoms / energy / time / mass. What does physics actually permit?
2. **Idiot index** — Cost of a finished thing / cost of its raw materials. High idiot index = manufacturing inefficiency, huge improvement margin.
3. **The 5-step algorithm**:
   1. **Make requirements less dumb** (the "dumbest part of the smartest engineer")
   2. **Delete the part or process** (if you don't have to add it back ≥10%, you didn't delete enough)
   3. **Simplify or optimize** (only after you've tried to delete)
   4. **Accelerate cycle time**
   5. **Automate** (last, not first)
4. **Vertical integration** — When suppliers / regulators / incumbents block step-change, build the whole stack yourself.
5. **Aggressive timelines as forcing function** — Most of the time the timeline is impossible. The 20% of the time it isn't, you compress decades.

## Decision heuristics

- If a part is "off the shelf" → assume it's 5-10× more expensive than necessary; check the idiot index.
- If a regulation says no → ask if the regulation is right or just default.
- If a process has too many steps → delete steps; if you have to add 1 back, that was the line.
- If a forecast says years → demand the physics-based bound: what's the actual minimum?
- If a team says "it's industry standard" → that's exactly the wrong reason to keep it.
