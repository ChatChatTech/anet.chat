# Abstract

Incremental and decremental learning (IDL) deals with the tasks where new data arrives sequentially as a stream or old data turns unavailable continually due to the privacy protection. Existing IDL methods mainly focus on support vector machine and its variants with linear-type loss. There are few studies about the quadratic-type loss, whose Lagrange multipliers are unbounded and much more diffcult to track. In this paper, we take the latest statistical learning framework optimal margin distribution machine (ODM) which involves a quadratic-type loss due to the optimization of margin variance, for example, and equip it with the ability to handle IDL tasks. Our proposed ID-ODM can avoid updating the Lagrange multipliers in an infnite range by determining their optimal values beforehand so as to enjoy much more effciency. Moreover, ID-ODM is also applicable when multiple instances come and leave simultaneously. Extensive empirical studies show that ID-ODM can achieve 9.1× speedup on average with almost no generalization lost compared to retraining ODM on new data set from scratch.

# 1 Introduction

For machine learning tasks, once data changes, the models should be refned. However, retraining models from scratch usually incurs unbearable cost or is even impossible in some situations, which gives rise to the incremental and decremental learning (IDL) [Schlimmer and Fisher, 1986; Cauwenberghs and Poggio, 2000]. This paradigm can effciently update the model and be applied in many learning problems, just to name a few, anomaly detection [Laxhammar and Falkman, 2014; Nguyen et al., 2019], concept drifting [Syed et al., 1999; Galmeanu and Andonie, 2022 ˆ ], active learning [Ertekin et al., 2007; Huang et al., 2020], privacy protection [Nguyen et al., 2020; Sekhari et al., 2021] , and model estimation [Cherubin et al., 2021].

Existing IDL methods mainly focus on support vector machine (SVM) [Cortes and Vapnik, 1995] and its variants. We summarize the representative works of this line in Table 1. Based on the path following method, IDSVM [Cauwenberghs and Poggio, 2000] takes both incremental learning and decremental learning into account to update SVM. MID-SVM [Karasuyama and Takeuchi, 2009] is a batch version of IDSVM. AONSVM [Gu et al., 2012] and FISVDD [Jiang et al., 2019] extends the ν-SVM [Scholkopf ¨ et al., 2000] and SVDD [Tax and Duin, 2004] to incremental learning, respectively. All these models use hinge loss. Besides, IL-S3VM [Gu et al., 2018] and ILTSVM [Chen et al., 2023] are incremental semi-supervised SVMs with symmetric hinge loss or its variant ramp loss.

On the one hand, the aforementioned methods mainly focus on large margin models, but the latest theoretical studies [Gao and Zhou, 2013] disclose that the margin distribution is much more critical to the generalization performance. On the other hand, these methods are limited to linear-type loss, in which the hinge loss is sensitive to outliers and symmetric hinge loss leads to non-convex optimization problems. In contrast, the quadratic-type loss is smoother and numerically easier to deal with. It results in a strictly diagonally dominant matrix in dual quadratic form which is always invertible, thus relaxes the restriction of linear-type loss that data should be linearly independent. As far as we know, there are few IDL methods concerning models with quadratic-type loss.

In this paper, we take the latest statistical learning framework optimal margin distribution machine (ODM) [Zhang and Zhou, 2019] which involves a quadratic-type loss due to the optimization of margin variance as an example and equip it with the ability to handle IDL tasks. The drawback of quadratic-type loss lies in the optimization aspect, that is the Lagrange multipliers are unbounded and much more diffcult to track when data varies, and existing IDL methods with linear-type loss can hardly be adapted to these circumstances. To overcome this diffculty, we estimate the optimal value of the Lagrange multiplier of the varying data in advance to avoid the optimization in an infnite range, and then update along the fastest direction to make the interruption by breakpoints less frequent. We also theoretically analyze the time complexity and convergence of our proposed incremental and decremental ODM (ID-ODM). The remarkable advantages are as follows:

• It is the frst attempt to implement IDL for kernel methods optimizing the margin distribution.

# 2 Preliminaries

We frst introduce some conventions and notations used throughout the paper. The normal font letters $( \mathrm { e } . \mathrm { g } . , y )$ denote scalars. The boldface letters (e.g., w and W) denote vectors and matrices, respectively. The upper case letters with mathcal font $( \mathrm { e } . \mathrm { g } . , S )$ indicate the sets. Particularly, [m] is defned as the integer set $\{ 1 , 2 , . . . , m \} . { \ w } _ { \ / s }$ indicates the vector consisting of the entries of w specifed by index set S. Similarly, $\mathbf { W } _ { S , S ^ { \prime } }$ is the submatrix of W specifed by row index set S and column index set $S ^ { \prime }$ .

For a binary classifcation problem, let $\boldsymbol { \mathcal { X } } \subseteq \mathbb { R } ^ { d }$ and $\mathcal { V } =$ $\{ 1 , - 1 \}$ denote the instance space and label set, respectively. The training set $\{ ( \boldsymbol { x } _ { i } , y _ { i } ) \} _ { i \in [ m ] } \in ( \mathcal { X } \times \mathcal { Y } ) ^ { m }$ is drawn i.i.d from some underlying distribution on $\mathcal { X } \times \mathcal { V } .$ . Let $\phi : { \mathcal { X } } \mapsto$ H be a feature mapping associated with some positive defnite kernel κ where H is the corresponding reproducing kernel Hilbert space (RKHS). The hypothesis is defned as the linear function $f ( \pmb { x } ) = \langle \pmb { w } , \phi ( \pmb { x } ) \rangle _ { \mathbb { H } }$ .

This linear decision function naturally leads to the defnition of margin, $\mathrm { i . e . , } \ \gamma ( { \pmb x } , y ) = y \langle { \pmb w } , \phi ( { \pmb x } ) \rangle _ { \mathbb { H } }$ . Notice that $f$ misclassifes $( { \pmb x } , y )$ if and only if it produces a negative margin, thus it represents the confdence of the prediction results. Recent studies on margin theory reveal that margin distribution is more important to generalization than a single margin, which gives rise to the ODM:

$$
\min _ {\boldsymbol {w}, \xi_ {i}, \epsilon_ {i}} \frac {1}{2} \| \boldsymbol {w} \| _ {\mathbb {H}} ^ {2} + \frac {\lambda}{2} \sum_ {i \in [ m ]} (\xi_ {i} ^ {2} + \epsilon_ {i} ^ {2}), \tag {1}
$$

$$
\text { s   .   t   . } 1 - \theta - \xi_ {i} \leq \gamma_ {i} \leq 1 + \theta + \epsilon_ {i}, \forall i \in [ m ],
$$

where $\gamma _ { i } = y _ { i } f ( { \pmb x } _ { i } )$ and λ is the trade-off hyperparameter. The margin mean has been fxed as 1 since scaling w does not affect the decision boundary. The slack variables $\xi _ { i }$ and $\epsilon _ { i }$ represent the deviation from the strip centered at margin mean with width 2θ. The hyperparameter θ is to tolerate the tiny deviations smaller than θ. When it is set as 0, the third term is exactly the margin variance.

Introducing the Lagrange multipliers $\zeta _ { i } \geq 0$ and $\beta _ { i } \geq 0$ for constraints leads to the Lagrangian of Eqn. (1):

$$
\begin{array}{l} L = \frac {1}{2} \| \boldsymbol {w} \| _ {\mathbb {H}} ^ {2} - \sum_ {i \in [ m ]} \zeta_ {i} (\gamma_ {i} - (1 - \theta - \xi_ {i})) \\ + \frac {\lambda}{2} \sum_ {i \in [ m ]} (\xi_ {i} ^ {2} + \epsilon_ {i} ^ {2}) + \sum_ {i \in [ m ]} \beta_ {i} (\gamma_ {i} - (1 + \theta + \epsilon_ {i})). \\ \end{array}
$$

The KKT conditions [Boyd and Vandenberghe, 2004] are

$$
\boldsymbol {w} = \sum_ {i \in [ m ]} y _ {i} \left(\zeta_ {i} - \beta_ {i}\right) \phi \left(\boldsymbol {x} _ {i}\right), \lambda \xi_ {i} = \zeta_ {i}, \lambda \epsilon_ {i} = \beta_ {i},
$$

$$
\zeta_ {i} (\gamma_ {i} - (1 - \theta) + \xi_ {i}) = 0, \tag {2}
$$

$$
\beta_ {i} (\gamma_ {i} - (1 + \theta) - \epsilon_ {i}) = 0. \tag {3}
$$

The analysis on complementary slackness conditions, i.e., Eqn. (2)-(3), leads to the partition of data into three sets:

$\bullet \ \mathcal { L } = \{ i \mid \gamma _ { i } < 1 - \theta , \zeta _ { i } > 0 , \beta _ { i } = 0 \} ,$   
$\bullet \ { \mathcal { C } } = \{ i \mid \gamma _ { i } \in [ 1 - \theta , 1 + \theta ] , \zeta _ { i } = 0 , \beta _ { i } = 0 \} ,$   
$\bullet \ \mathcal { R } = \{ i \mid \gamma _ { i } > 1 + \theta , \zeta _ { i } = 0 , \beta _ { i } > 0 \} ,$

which are shown in Figure 1(a), respectively. Besides, let $\alpha _ { i } = \zeta _ { i } - \beta _ { i }$ and $S = \mathcal { L } \cup \mathcal { R }$ is the index set of instances whose $\alpha _ { i } \neq 0$ , the decision function can be rewritten as

$$
f (\boldsymbol {x} _ {i}) = \langle \boldsymbol {w}, \phi (\boldsymbol {x} _ {i}) \rangle_ {\mathbb {H}} = \sum_ {j \in \mathcal {S}} \alpha_ {j} y _ {j} \kappa_ {i j} \tag {4}
$$

with $\kappa _ { i j } = \kappa ( \pmb { x } _ { i } , \pmb { x } _ { j } )$ .

# 3 ID-ODM for Single Instance Varying

In this section, we investigate the case when single instance comes or leaves.

# 3.1 Incremental Case

Suppose the new instance is $( x _ { k } , y _ { k } )$ . $\mathrm { I f } \gamma _ { k } \in [ 1 - \theta , 1 + \theta ]$ , acccording to Eqn. (4), this instance can be directly added to $\mathcal { C }$ without any update. Thus without loss of generality, we assume $\gamma _ { k } \notin [ 1 - \theta , 1 + \theta ]$ and initialize the Lagrange multiplier $\alpha _ { k }$ as 0. Next, we frst derive the relationship between $\alpha _ { \mathcal { S } }$ and $\alpha _ { k }$ , and then detail how to update $\alpha _ { \mathcal { S } }$ by varying $\alpha _ { k }$ gradually.

The relationship between $\alpha _ { \mathcal { S } }$ and $\alpha _ { k }$ . Notice that $1 \pm \theta$ are constants, to make the KKT conditions hold, i.e.,

$$
\gamma_ {i} + \xi_ {i} = 1 - \theta , \quad \forall i \in \mathcal {L},
$$

$$
\gamma_ {i} - \epsilon_ {i} = 1 + \theta , \quad \forall i \in \mathcal {R},
$$

the Lagrange multiplier $\alpha _ { \mathcal { S } }$ should vary with $\alpha _ { k }$ such that

$$
\Delta \gamma_ {i} + \Delta \xi_ {i} = 0, \quad \forall i \in \mathcal {L}, \tag {5}
$$

$$
\Delta \gamma_ {i} - \Delta \epsilon_ {i} = 0, \quad \forall i \in \mathcal {R}, \tag {6}
$$

where $\Delta$ denotes the variations of variables. With Eqn. (4), we have

$$
\Delta \gamma_ {i} = y _ {i} \Delta f (\boldsymbol {x} _ {i}) = \sum_ {j \in \mathcal {S}} \Delta \alpha_ {j} y _ {i} y _ {j} \kappa_ {i j} + \Delta \alpha_ {k} y _ {i} y _ {k} \kappa_ {i k}. \tag {7}
$$

Notice that $\alpha _ { i } = \lambda \xi _ { i }$ for $\forall i \in { \mathcal { L } }$ and $\alpha _ { i } = - \lambda \epsilon _ { i }$ for $\forall i \in \mathcal { R }$ , we can derive the following linear system

$$
\sum_ {j \in \mathcal {S}} \Delta \alpha_ {j} h _ {i j} + \Delta \alpha_ {k} h _ {i k} + \Delta \alpha_ {i} / \lambda = 0,   \forall i \in \mathcal {S}, \tag {8}
$$

where $h _ { i j } = y _ { i } y _ { j } \kappa _ { i j }$ . Denote $\mathbf { H } = ( h _ { i j } ) _ { i , j \in [ k ] }$ , then Eqn. (8) can be rewritten in a matrix form

$$
\left(\mathbf {H} _ {\mathcal {S S}} + \mathbf {I} _ {| \mathcal {S} |} / \lambda\right) \Delta \boldsymbol {\alpha} _ {\mathcal {S}} = - \mathbf {H} _ {\mathcal {S} k} \Delta \alpha_ {k},
$$

which implies that $\Delta \alpha _ { \mathcal { S } }$ varies linearly with $\Delta \alpha _ { k }$

$$
\Delta \alpha_ {S} = - \mathbf {Q} _ {S} ^ {- 1} \mathbf {H} _ {S k} \Delta \alpha_ {k} = t \Delta \alpha_ {k}, \tag {9}
$$

where $\mathbf { Q } _ { S } = \mathbf { H } _ { S S } + \mathbf { I } _ { | S | } / \lambda$ and ${ \pmb t } = - { \bf Q } _ { S } ^ { - 1 } { \bf H } _ { S k }$ .

Update $\alpha _ { k } .$ . By substituting Eqn. (9) into Eqn. (7) to eliminate $\Delta \alpha _ { \mathcal { S } }$ , the remaining variable is only $\Delta \alpha _ { k }$ . We can monitor the variation of margin with $\Delta \alpha _ { k }$ for all instances.

Different from previous works like [Cauwenberghs and Poggio, 2000] in which $\alpha _ { k }$ belongs to [0, C] and can be simply updated by increasing gradually from 0 to C, here $\alpha _ { k } \in \mathbb { R }$ is unbounded, and we do not even know whether to increase or decrease $\alpha _ { k }$ . Fortunately, if $( \boldsymbol { x } _ { k } , y _ { k } )$ is successfully added, by KKT conditions, we have

$$
\gamma_ {k} + \Delta \gamma_ {k} ^ {\star} + (\alpha_ {k} + \Delta \alpha_ {k} ^ {\star}) / \lambda = d, \tag {10}
$$

where

$$
d = \left\{ \begin{array}{l l} 1 - \theta , & \gamma_ {k} <   1 - \theta , \\ 1 + \theta , & \gamma_ {k} > 1 + \theta . \end{array} \right. \tag {11}
$$

With Eqn. (7) and Eqn. (9), we have a closed-form solution

$$
\Delta \alpha_ {k} ^ {\star} = \frac {d - \gamma_ {k} - \alpha_ {k} / \lambda}{1 + 1 / \lambda + \mathbf {H} _ {k S} t}. \tag {12}
$$

The above analysis is based on the assumption that the three index sets ${ \mathcal { L } } , { \mathcal { C } } ,$ and R remain unchanged when $\alpha _ { k }$ is varying, thus Eqn. (12) is not an actual optimal solution, but it can provide a credible update direction. In practice, we can let $\Delta \alpha _ { k } = \eta \Delta \alpha _ { k } ^ { \star }$ and increases η from 0 to 1 gradually. At the same time, we monitor the three index sets. When one of the following events occurs

• $i \in S$ migrates to C, i.e., nonzero $\alpha _ { i }$ turns to 0,   
• $i \in \mathcal { C }$ migrates to $S , \mathrm { i . e . , } f ( { \pmb x } _ { i } )$ reaches the boundary of the strip as shown in Figure 1,

we call a breakpoint is detected and sequentially perform the following four steps

1. Stop the increase of $\eta .$   
2. Update the index sets ${ \mathcal { L } } , { \mathcal { C } } .$ , and $\mathcal { R } .$ .   
3. Record the current $\alpha _ { k }$ and $\alpha _ { \mathcal { S } }$ .   
4. Update H, t, and $\Delta \alpha _ { k } ^ { \star } .$

The above procedure is repeated until no breakpoint is detected during the increase of $\eta$ from 0 to 1, then $( \boldsymbol { x } _ { k } , \boldsymbol { y } _ { k } )$ can be added to L or R based on current $\gamma _ { k }$ .

# 3.2 Decremental Case

Suppose the invalid instance is $( \boldsymbol { x } _ { k } , y _ { k } )$ . I $\ : \dot { \boldsymbol { \cdot } } \ : \boldsymbol { k } \in \mathcal { C } , \mathrm { i . e . , } \alpha _ { k } = \ :$ 0, it has no contribution to the model and can be removed directly. Thus without loss of generality, we assume $k \in S .$ . Now we need to turn $\alpha _ { k }$ to 0 to totally eliminate its effect on the model. Analogous to the incremental case, we frst update $S = S \setminus \{ k \}$ and derive the relationship between $\alpha _ { \mathcal { S } }$ and $\alpha _ { k } .$ , and then show how to update $\alpha _ { \mathcal { S } }$ by varying $\alpha _ { k }$ .

The relationship between $\alpha _ { \mathcal { S } }$ and $\alpha _ { k }$ . Since we should make KKT conditions hold at any time, the deletion of $\alpha _ { k }$ from $s$ can be viewed as the reverse process of addition of $\alpha _ { k }$ to S . Again, $\Delta \alpha _ { \mathcal { S } }$ and $\Delta \alpha _ { k }$ satisfy

$$
\left(\mathbf {H} _ {\mathcal {S S}} + \mathbf {I} _ {| \mathcal {S} |} / \lambda\right) \Delta \boldsymbol {\alpha} _ {\mathcal {S}} = - \mathbf {H} _ {\mathcal {S} k} \Delta \alpha_ {k}.
$$

Since $\Delta \alpha _ { \mathcal { S } }$ changes linearly with $\Delta \alpha _ { k } ,$ , we can trace the variation of the margin with $\Delta \alpha _ { k }$ .

Update $\alpha _ { k }$ . The update is now reduced to determine $\Delta \alpha _ { k }$ . Distinct from the incremental case, the invalid data vanishes and the algorithm terminates with $\Delta \alpha _ { k } ^ { \star } = - \alpha _ { k }$ .

As a result, we can update $\alpha _ { k }$ with $\Delta \alpha _ { k } = - \eta \alpha _ { k }$ . Like the incremental case, each update is comprised of four steps when we keep watch on breakpoints. The whole procedure stops when $\eta = 1$ .

In this section, we frst present the general ID-ODM for multiple instances varying and then analyze the time complexity and convergence.

# 4.1 Multiple Instances Varying

Without loss of generality, we assume that there are p instances $\{ ( x _ { i } , y _ { i } ) \} _ { i \in \mathcal { E } }$ becoming available and $q$ instances $\{ ( { \pmb x } _ { j } , y _ { j } ) \} _ { j \in \mathbb { Z } }$ turning invalid where

$$
\mathcal {E} = \{m + 1, m + 2, \dots , m + p \}, \quad \mathcal {I} \subseteq \mathcal {S}.
$$

We denote $\mathcal { A } = \mathcal { E } \cup \mathcal { T }$ to represent all varying instances for convenience. The most straightforward way is to view each single instance individually and invoke the method in Section 3.1 and 3.2 for $p$ times and q times, respectively. Nevertheless, this scheme is computationally ineffcient as shown in Figure 2(a).

One smarter way is to update $\alpha \varepsilon$ and $\alpha _ { \mathcal { T } }$ simultaneously as shown in Figure $2 ( \mathsf { b } )$ . Under this circumstance, multiple new instances satisfy the optimal conditions, and multiple invalid instances are removed at the same time. In the same manner as before, we frst update $\begin{array} { r } { S = S \setminus \mathcal { T } } \end{array}$ and derive the relationship between $\alpha _ { \mathcal { S } }$ and $\alpha _ { \mathcal { A } }$ , and then show how to update $\alpha \varepsilon$ and $\alpha _ { \mathcal { T } }$ simultaneously.

The relationship between $\alpha _ { \mathcal { S } }$ and $\alpha _ { \mathcal { A } }$ . Different from the single instance case where $\Delta \alpha _ { k }$ is a scalar, now $\Delta \alpha _ { \mathcal { S } }$ varies with the vector $\Delta \alpha _ { \mathcal { A } }$ . The margin change of $( { \pmb x } _ { i } , y _ { i } )$ is described as

$$
\begin{array}{l} \Delta \gamma_ {i} = \sum_ {j \in \mathcal {S}} \Delta \alpha_ {j} y _ {i} y _ {j} \kappa_ {i j} + \sum_ {k \in \mathcal {A}} \Delta \alpha_ {k} y _ {i} y _ {k} \kappa_ {i k} \\ = \mathbf {H} _ {i S} \Delta \boldsymbol {\alpha} _ {S} + \mathbf {H} _ {i A} \Delta \boldsymbol {\alpha} _ {A} \tag {13} \\ \end{array}
$$

In order to make KKT conditions hold, $\Delta \alpha _ { \mathcal { S } } , \ \Delta \alpha _ { \mathcal { E } }$ , and $\Delta \alpha _ { \mathcal { T } }$ should satisfy

$$
\left(\mathbf {H} _ {\mathcal {S S}} + \mathbf {I} / \lambda\right) \Delta \alpha_ {\mathcal {S}} + \mathbf {H} _ {\mathcal {S A}} \Delta \alpha_ {\mathcal {A}} = \mathbf {0}.
$$

Thus, $\Delta \alpha _ { \mathcal { S } }$ can be traced by $\Delta \alpha _ { \mathcal E }$ and $\Delta \alpha _ { \mathcal { I } }$ according to

$$
\Delta \boldsymbol {\alpha} _ {S} = - \mathbf {Q} _ {S} ^ {- 1} \mathbf {H} _ {S A} \Delta \boldsymbol {\alpha} _ {A} = \left[ \begin{array}{l l} \mathbf {T} _ {S E} & \mathbf {T} _ {S I} \end{array} \right] \left[ \begin{array}{l} \Delta \boldsymbol {\alpha} _ {\varepsilon} \\ \Delta \boldsymbol {\alpha} _ {I} \end{array} \right] \tag {14}
$$

where $\mathbf { T } _ { S \mathcal { E } } = - \mathbf { Q } _ { \mathcal { S } } ^ { - 1 } \mathbf { H } _ { \mathcal { S } \mathcal { E } }$ and $\mathbf { T } _ { S \mathcal { T } } = - \mathbf { Q } _ { \mathcal { S } } ^ { - 1 } \mathbf { H } _ { { S \mathcal { T } } }$ .

Update $\alpha _ { \mathcal { A } }$ . The critical point to update the model lies in identifying $\Delta \alpha _ { \mathcal { A } }$ . Intuitively, $\alpha _ { \mathcal { T } }$ is supposed to update along the opposite direction of $\alpha _ { \mathcal { T } }$ to remove the invalid data. In other words, $\Delta \alpha _ { \mathscr I } = - \eta \alpha _ { \mathscr I }$ . As for $\alpha _ { \mathcal { E } }$ , we determine the update direction $\Delta \alpha _ { \mathcal E }$ by keeping KKT conditions w.r.t the new instances. Since multiple instances arrive, Eqn. (10) can be recast in

$$
\boldsymbol {d} _ {\mathcal {E}} = \gamma_ {\mathcal {E}} + \mathrm{H} _ {\mathcal {E S}} \Delta \alpha_ {\mathcal {S}} ^ {\star} + \mathrm{H} _ {\mathcal {E A}} \Delta \alpha_ {\mathcal {A}} ^ {\star} + (\alpha_ {\mathcal {E}} + \Delta \alpha_ {\mathcal {E}} ^ {\star}) / \lambda ,
$$

where d is the vector with the k-th entry $d _ { k }$ defned in Eqn. (11). By denoting $\Delta \alpha _ { \mathcal { S } }$ via $\Delta \alpha _ { \mathcal { E } }$ and $\Delta \alpha _ { \mathcal { T } }$ , we can determine $\Delta \dot { \alpha } _ { \mathcal E } ^ { \star }$ by

$$
\begin{array}{l} \Delta \boldsymbol {\alpha} _ {\mathcal {E}} ^ {\star} = (\mathbf {Q} _ {\mathcal {E}} + \mathbf {H} _ {\mathcal {E S}} \mathbf {T} _ {\mathcal {S E}}) ^ {- 1} (\boldsymbol {d} _ {\mathcal {E}} - \boldsymbol {\gamma} _ {\mathcal {E}} - \boldsymbol {\alpha} _ {\mathcal {E}} / \lambda) \\ - \left(\mathbf {Q} _ {\mathcal {E}} + \mathbf {H} _ {\mathcal {E S}} \mathbf {T} _ {\mathcal {S E}}\right) ^ {- 1} \left(\mathbf {H} _ {\mathcal {E S}} \mathbf {T} _ {\mathcal {S I}} + \mathbf {H} _ {\mathcal {E I}}\right) \Delta \boldsymbol {\alpha} _ {\mathcal {I}} ^ {\star}. \\ \end{array}
$$

It seems that $\Delta \alpha _ { \varepsilon } ^ { \star }$ is relevant to $\Delta \alpha _ { \mathcal { T } } ^ { \star }$ , but when no breakpoint is produced, $\Delta \alpha _ { \mathscr I } ^ { \star } = - \alpha _ { \mathscr I }$ is fxed. Consequently, we update $\alpha _ { \mathcal { A } }$ via

$$
\Delta \boldsymbol {\alpha} _ {\mathcal {A}} = \left[ \begin{array}{c} \Delta \boldsymbol {\alpha} _ {\mathcal {E}} \\ \Delta \boldsymbol {\alpha} _ {\mathcal {I}} \end{array} \right] = \eta \left[ \begin{array}{c} \Delta \boldsymbol {\alpha} _ {\mathcal {E}} ^ {\star} \\ - \boldsymbol {\alpha} _ {\mathcal {I}} \end{array} \right]
$$

and track $\Delta \alpha _ { \mathcal { S } }$ and $\Delta f ( { \pmb x } )$ by searching for the minimal η which will lead to a breakpoint or the termination of ID-ODM. Algorithm 1 summarizes the pseudo-code for ID-ODM.

# 4.2 Time Complexity

According to the Algorithm 1, the main time cost is caused by computing the inverse of the matrix $\mathbf { Q } _ { \mathcal { S } }$ . It is well accepted that the time complexity of computing the inverse of a n-order square matrix is $\mathcal { O } ( n ^ { 3 } )$ . If we calculate $\mathbf { Q } _ { \mathcal { S } } ^ { - 1 }$ at each iteration, the time complexity is $\mathcal { O } ( c ( m + p - q ) ^ { 3 } )$ , where c is the number of breakpoints. Hence it is very time-consuming. However, by resorting to Sherman-Morrison-Woodbury formula [Golub and Van Loan, 1983], we can reduce the time cost to $\mathcal { O } ( c ( m + p - q ) ^ { 2 } )$ .

Suppose a new instance $( \pmb { x } _ { c } , y _ { c } )$ is added to S , let ${ \boldsymbol { S } } ^ { \prime } =$ $S \cup \{ c \}$ , then we have

$$
\mathbf {Q} _ {\mathcal {S} ^ {\prime}} = \left[ \begin{array}{c c} \mathbf {Q} _ {\mathcal {S}} & \mathbf {H} _ {\mathcal {S} c} \\ \mathbf {H} _ {c \mathcal {S}} & \mathbf {H} _ {c c} + 1 / \lambda \end{array} \right] = \left[ \begin{array}{c c} \mathbf {Q} _ {\mathcal {S}} & \mathbf {H} _ {\mathcal {S} c} \\ \mathbf {H} _ {c \mathcal {S}} & \kappa_ {c c} + 1 / \lambda \end{array} \right].
$$

The Schur’s complement [Zhang, 2006] of $\mathbf { Q } _ { \mathcal { S } }$ is ${ \bf S } = \kappa _ { c c } +$ $1 / \lambda - \mathbf { H } _ { c S } \mathbf { Q } _ { S } ^ { - 1 } \mathbf { \dot { H } } _ { S c }$ . According to the Sherman-Morrison-Woodbury formula,

$$
\begin{array}{l} \mathbf {Q} _ {\mathcal {S} ^ {\prime}} ^ {- 1} = \left[ \begin{array}{c c} \mathbf {Q} _ {\mathcal {S}} ^ {- 1} + \mathbf {Q} _ {\mathcal {S}} ^ {- 1} \mathbf {H} _ {\mathcal {S} c} \mathbf {S} ^ {- 1} \mathbf {H} _ {c \mathcal {S}} \mathbf {Q} _ {\mathcal {S}} ^ {- 1} & - \mathbf {Q} _ {\mathcal {S}} ^ {- 1} \mathbf {H} _ {\mathcal {S} c} \mathbf {S} ^ {- 1} \\ - \mathbf {S} ^ {- 1} \mathbf {H} _ {c \mathcal {S}} \mathbf {Q} _ {\mathcal {S}} ^ {- 1} & \mathbf {S} ^ {- 1} \end{array} \right] \\ = \left[ \begin{array}{c c} \mathbf {Q} _ {\mathcal {S}} ^ {- 1} & \mathbf {0} \\ \mathbf {0} & \mathbf {0} \end{array} \right] + \left[ \begin{array}{l} \boldsymbol {v} \\ 1 \end{array} \right] \mathbf {S} ^ {- 1} \left[ \begin{array}{l l} \boldsymbol {v} ^ {\top} & 1 \end{array} \right], \tag {15} \\ \end{array}
$$

where $\pmb { v } = - \mathbf { Q } _ { \mathcal { S } } ^ { - 1 } \mathbf { H } _ { \mathcal { S } c }$

As for the decremental case, we can exchange the roles of $s$ and $S ^ { \prime }$ , and calculate $\mathbf { Q } _ { S ^ { \prime } } ^ { - 1 }$ in the same manner.

# 4.3 Convergence

According to Eqn. (9), ID-ODM depends on the existence of $\mathbf { Q } _ { S } ^ { - 1 }$ . Fortunately, for quadratic-type loss, Q is strictly diagonally dominant and positive defnite, thus its inverse always exists.

When an instance $( x _ { k } , y _ { k } )$ comes or leaves, $\alpha _ { k }$ varies, the classifcation hyperplane evolves, and αS monotonically increases or decreases [Laskov et al., 2006]. To guarantee the convergence of Algorithm 1, we should further prove the monotonic update of $\alpha _ { \mathcal { S } }$ is strict, that is no instance migrates between index sets back and forth.

Theorem 1 (Immediate cycling will not occur). If a breakpoint $( \pmb { x } _ { c } , y _ { c } )$ migrates from C to S or vice versa in round t, it will not come back in the next round.

Proof. ${ \mathcal { C } } \to S { \mathrm { : } }$ Suppose $( \pmb { x } _ { c } , y _ { c } )$ migrates from C to L. Before it enters ${ \mathcal { L } } ,$ we always have $\alpha _ { c } ^ { ( t ) } = 0$ . If it comes back from L to C in the next round, its margin will increase, i.e., $\Delta \gamma _ { c } ^ { ( t + 1 ) } > 0$ . Notice that $\Delta \gamma _ { i } = - \Delta \alpha _ { i } / \lambda , \forall i \in \mathcal { L }$ according to Eqn. (5), which implies $\Delta \alpha _ { c } ^ { ( t + 1 ) } < 0$ α(t+1)c < 0. Together with $\alpha _ { c } ^ { ( t ) } = 0$ αc , we have $\alpha _ { c } ^ { ( t + 1 ) } < 0 .$ A contradiction occurs since $\alpha _ { i } > 0 , \forall i \in \mathcal { L }$ .

The proof of migration from C to R is similar. If $( \boldsymbol { x } _ { c } , \boldsymbol { y } _ { c } )$ comes back from R to C in the next round, its margin will decrease, and we have $\Delta \gamma _ { c } ^ { ( t + 1 ) } < 0$ and $\Delta \alpha _ { c } ^ { ( t + 1 ) } > 0$ by noticing that $\Delta \gamma _ { i } = - \Delta \alpha _ { i } / \lambda , \forall i \in \mathcal { R }$ according to Eqn. (6). Together with $\alpha _ { c } ^ { ( t ) } = 0 .$ , we have $\alpha _ { c } ^ { ( t + 1 ) } > 0$ , which contradicts with $\alpha _ { i } < 0 , \forall i \in \mathcal { R }$ .

$s  c \mathrm { : }$ It is equivalent to prove that the margin varies monotonically, i.e., $\bar { \Delta } \gamma _ { c } ^ { ( t + 1 ) }$ and $\Delta \gamma _ { c } ^ { ( t ) }$ have the same sign.

Before a breakpoint turns out in round t, the index sets are ${ \mathcal { S } } ^ { ( t - 1 ) }$ and $\mathcal { C } ^ { ( { \hat { t } } - 1 ) }$ . Obviously the migration of $( \boldsymbol { x } _ { c } , \boldsymbol { y } _ { c } )$ from ${ \mathcal { S } } ^ { ( t - 1 ) }$ to $\mathcal { C } ^ { ( t ) }$ can be viewed as the reverse process of migration from $\mathcal { C } ^ { ( t ) } \mathrm { t o } S ^ { ( t - 1 ) }$ . Thus, we can calculate $\mathbf { \Delta } _ { t ^ { ( t ) } }$ as

$$
\begin{array}{l} \boldsymbol {t} ^ {(t)} = - \mathbf {Q} _ {\mathcal {S} ^ {(t - 1)}} ^ {- 1} \mathbf {H} _ {\mathcal {S} ^ {(t - 1)} k} \\ = - \left(\left[ \begin{array}{c c} \mathbf {Q} _ {\mathcal {S} ^ {(t)}} ^ {- 1} & \mathbf {0} \\ \mathbf {0} & \mathbf {0} \end{array} \right] + \left[ \begin{array}{l} \boldsymbol {v} \\ 1 \end{array} \right] \mathbf {S} ^ {- 1} \left[ \begin{array}{l l} \boldsymbol {v} ^ {\top} & 1 \end{array} \right]\right) \mathbf {H} _ {\mathcal {S} ^ {(t - 1)} k} \tag {16} \\ = \left[ \begin{array}{c} \boldsymbol {t} ^ {(t + 1)} \\ 0 \end{array} \right] - \left[ \begin{array}{c} \boldsymbol {v} \\ 1 \end{array} \right] \mathbf {S} ^ {- 1} \left(\boldsymbol {v} ^ {\top} \mathbf {H} _ {\mathcal {S} ^ {(t)} k} + \mathbf {H} _ {c k}\right), \\ \end{array}
$$

where S is the Shur’s complement of $\mathbf { Q } _ { S ^ { ( t - 1 ) } }$ , and the frst and last equality are according to the defnition of $t , v ,$ , and Eqn. (15), respectively. With Eqn. (16), we have

$$
\begin{array}{l} \Delta \alpha_ {c} ^ {(t)} = - \mathbf {S} ^ {- 1} \left(\boldsymbol {v} ^ {\top} \mathbf {H} _ {\mathcal {S} ^ {(t)} k} + \mathbf {H} _ {c k}\right) \Delta \alpha_ {k} ^ {(t)} \\ = - \mathbf {S} ^ {- 1} \left(- \mathbf {H} _ {c \mathcal {S} ^ {(t)}} \mathbf {Q} _ {\mathcal {S} ^ {(t)}} ^ {- 1} \mathbf {H} _ {\mathcal {S} ^ {(t)} k} + \mathbf {H} _ {c k}\right) \Delta \alpha_ {k} ^ {(t)}. \tag {17} \\ \end{array}
$$

Then we can further calculate the variation of margin for the instance $( \pmb { x } _ { c } , y _ { c } )$ in round $t + 1$ as

$$
\begin{array}{l} \Delta \gamma_ {c} ^ {(t + 1)} = \sum_ {j \in \mathcal {S} ^ {(t)}} \Delta \alpha_ {j} ^ {(t + 1)} h _ {c j} + \Delta \alpha_ {k} ^ {(t + 1)} h _ {c k} \\ = \mathbf {H} _ {c \mathcal {S} ^ {(t)}} \Delta \alpha_ {\mathcal {S} ^ {(t)}} ^ {(t + 1)} + \mathbf {H} _ {c k} \Delta \alpha_ {k} ^ {(t + 1)} \\ = \left(- \mathbf {H} _ {c \mathcal {S} ^ {(t)}} \mathbf {Q} _ {\mathcal {S} ^ {(t)}} ^ {- 1} \mathbf {H} _ {\mathcal {S} ^ {(t)} k} + \mathbf {H} _ {c k}\right) \Delta \alpha_ {k} ^ {(t + 1)}, \\ \end{array}
$$

where the frst and third equality are according to Eqn. (7) and Eqn. (9), respectively. With Eqn. (17), we have $\Delta \gamma _ { c } ^ { ( t + 1 ) } =$ −S∆α(t)c ∆ $- \mathbf { \dot { S } } \Delta \alpha _ { c } ^ { ( t ) } \Delta \dot { \alpha _ { k } ^ { ( t + 1 ) } } / \dot { \Delta } \alpha _ { k } ^ { ( t ) }$ α(tk )/∆α(t)k .

Since the update of $\alpha _ { k }$ is monotonic, $\Delta \alpha _ { k } ^ { ( t ) }$ and $\Delta \alpha _ { k } ^ { ( t + 1 ) }$ have the same sign. Notice that $\Delta \alpha _ { c } ^ { ( t ) }$ has the opposite sign to $\Delta \gamma _ { c } ^ { ( t ) }$ , thus $\Delta \gamma _ { c } ^ { ( \overline { { t } } + 1 ) }$ has the same sign with $\Delta \gamma _ { c } ^ { ( t ) } \ \mathrm { i f } \ \mathbf { S } > 0$ . Since $\mathbf { Q } _ { \mathcal { S } }$ is a positive defnite matrix, the corresponding Shur’s complement $\mathrm { ~ \bf ~ S ~ } > \mathrm { ~ 0 ~ }$ [Ouellette, 1981], which concludes the proof. For multiple instance changes, the proof is similar. □

# 6 Conclusions

In this paper, we propose the ID-ODM to effciently update ODM when new data is available or old data turns invalid. Specifcally, we avoid updating the unbounded Lagrange multipliers in an infnite range by estimating the optimal value beforehand, thus iteratively updating the model. Moreover, ID-ODM is effective no matter how data varies, thus it is applicable to various real-world tasks. Besides, we provide some theoretical analysis on ID-ODM. Extensive experiments validate the effectiveness and effciency of our method. In the future, we will extend our method to other models with quadratic-type loss.
